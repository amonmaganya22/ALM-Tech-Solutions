# ALM TECH SOLUTIONS - IT Services Website

This is the official website for ALM TECH SOLUTIONS, a professional IT services company based in Tanzania. The website is built with modern web technologies to provide a responsive and user-friendly experience across all devices.

## Features

- **Fully Responsive** - Works on all devices (desktops, tablets, and mobile phones)
- **Modern UI/UX** - Clean and professional design with smooth animations
- **Fast Performance** - Optimized for speed and performance
- **SEO Friendly** - Built with search engine optimization in mind
- **Contact Form** - Easy way for clients to get in touch
- **Social Media Integration** - Links to social media profiles

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts (Poppins)
